== Install the OpenSCAP client by running ansible roles

Recall that we configured the `RHEL10` host group to include the `theforeman.foreman_scap_client` Ansible role in module 5. In this module we'll run the Ansible role on the managed hosts to install and configure the OpenSCAP client.

The theforeman.foreman_scap_client Ansible role does three things:

Installs the rubygem-foreman_scap_client package on the host (from the Satellite Client repo). +
Configures /etc/foreman_scap_client/config.yaml with the Satellite proxy connection details and the compliance policies assigned to the host. +
Creates a cron job that schedules SCAP scans and automatically uploads the compliance reports (ARF files) back to Satellite.

When Satellite runs this role on a host, it automatically injects the correct values for the proxy server, port, and policy details — so the host knows which SCAP profiles to scan against and where to send the results.

For more information about the theforeman.foreman_scap_client Ansible role, see the following resources:

* https://github.com/theforeman/ansible-foreman_scap_client[theforeman/ansible-foreman_scap_client on GitHub]

* https://docs.redhat.com/en/documentation/red_hat_satellite/6.19/html/managing_security_compliance/deploying-compliance-policies_security-compliance[Deploying Compliance Policies - Red Hat Satellite 6.19]

=====
Next, we'll run the Ansible role on the managed hosts to install and configure the OpenSCAP client.

NOTE: The ansible role `theforeman.foreman_scap_client` is automatically scheduled to run on the managed hosts that are registered to the `RHEL10` host group. The purpose of this module is to show you how to manually run the ansible role on the managed hosts, should you choose not to wait for the automatic schedule. The scheduled job will run roughly 5 minutes after the hosts are registered. Ansible roles are idempotent, which means that they can be run multiple times without causing problems.

.Run the Ansible role on the managed hosts
[%collapsible]
====

Navigate to **Hosts > All Hosts**.

Do the following:

. Click on `rhel1.lab`.
. Click on the accordion button next to `Schedule a job` and select `Run Ansible roles`.

image::run-ansible-roles.png[]

While it's not necessary, feel free to run the ansible role on `rhel2.lab` if desired.
