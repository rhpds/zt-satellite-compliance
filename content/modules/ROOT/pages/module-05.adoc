== Configure a host group

Host groups are a way to create a standardized configuration for a group of hosts. Host groups allow you to define common settings, such as content views, lifecycle environments, and Ansible roles, that can be applied to multiple hosts. This simplifies the management of hosts and ensures consistency across your infrastructure.

In this particular lab, we'll create a host group that enables the OpenSCAP client to be installed on the managed hosts. The host group will be configured with the necessary content view, lifecycle environment, and Ansible role to ensure that the OpenSCAP client is properly set up for compliance scanning.

Navigate to **Configure > Host Groups ** and click on `Create Host Group`.

== Host group configuration procedure

Next, we'll configure the host group to include the necessary content view, lifecycle environment, and Ansible role to ensure that the OpenSCAP client is properly set up for compliance scanning.

=====
In this step we'll configure the host group details. This includes the name of the host group, the content source, the lifecycle environment, the content view, the OpenSCAP capsule, and the Ansible role.

.Host group configuration - Host Group details
[%collapsible]
====
In the `Create Host Group` window, enter the following details:

. Enter the name `RHEL10`.
. Select `satellite.lab` as the `Content Source`.
. Select the `Library` `Lifecycle Environment`.
. Select the `RHEL10` `Content View`.
. Select `satellite.lab` as the `OpenSCAP Capsule`.
. Click on the `Ansible Roles` tab.

.Host Group attributes
image::create-host-group-host-group.png[]

====
=====

=====
Next, we'll configure the Ansible roles to be used to install the OpenSCAP client on the managed hosts.

.Host group configuration - Ansible Roles
[%collapsible]
====
In the `Ansible Roles` tab, enter the following details:

. select the `theforeman.foreman_scap_client` role.
. Click on the `Activation Keys` tab.

.theforeman.foreman_scap_client role
image::theforeman-openscap-client-role.png[]

====
=====

=====
Next, we'll configure the activation key to be used to install the OpenSCAP client on the managed hosts.

.Host group configuration - Activation Keys
[%collapsible]
====
In the `Activation Keys` tab, enter the following details:

. Select the `RHEL10` activation key.
. Click `Submit` to create the host group.

.Activation Keys tab
image::host-group-activation-keys.png[]

====
=====

=====
Your host group is now configured.
